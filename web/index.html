Language guide

Astra is a small, typed-at-runtime scripting language built from scratch.

Variableslet n = 10;

Variables hold numbers, strings, booleans or null.

Functionsfn add(a, b) { return a+b; }

User functions can recurse and have scoped local variables.

Conditionsif (n > 0) { print(n); }

Use if/else, while, && and ||.

Built-insprint(x) len(s) str(x)
sqrt(n) assert(x)

Only these five functions are built in.

Comments// documentation

End each statement with a semicolon.

Limitations

No arrays, imports, classes, files or networking yet. String length counts UTF-8 bytes.
